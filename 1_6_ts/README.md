# Typization JS code with TypeScript

Solution of 7 small tasks aimed to understand TS.

## Usage

Source code located in src/ folder divided into 7 files (tasks) and main file (index.js).
To see the output in the console run the command `npm run build:start`.
To see the output in the browser console run the command `npm run build` and open index.html file in browser.
